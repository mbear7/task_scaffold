# --- on what these bounds do NOT do ---
#
# Lower bounds record what is required. They do nothing about the hazard
# that actually threatens this codebase, which is an UPGRADE: pandas 3
# changed object-column defaults to StringDtype, which converts None to
# nan, and this project is sensitive to missing-value semantics
# throughout. A future major could do something similar again and these
# bounds would not notice.
#
# Bounding that needs upper bounds or a lockfile, deliberately not adopted
# here. If a run starts producing nan where it used to produce NULL, check
# the pandas version first.
#
# Verified against: python 3.12.3 and 3.13.5, pandas 3.0.2, petl 1.7.17,
